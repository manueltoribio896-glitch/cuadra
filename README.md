# Cuadra — Revisa tu factura de luz

App web (se instala en el celular) para:
- Tomar foto del contador y comparar contra la factura.
- Subir el PDF de la factura de Edenorte y leerlo solo.
- Anotar apagones con un botón (“Se fue la luz / Volvió la luz”) o por voz.
- Pronosticar la próxima factura.
- Armar el reclamo en PDF con evidencias.

Los datos se guardan solo en el teléfono de quien la usa.
